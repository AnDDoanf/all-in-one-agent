A portable, standalone collection of 17 AI agent skills designed to operate across **OpenAI Codex**, **Anthropic Claude Code**, and **Google Gemini CLI / Antigravity**.

When cloned into any parent workspace containing projects, all coding agents share these exact skills and read/write a single unified `insight/` knowledge base in the workspace root.

## ⚡ Zero-Runtime Architecture (Pure Skills)

This repository adheres to the SOTA standard where **the AI agent is the runtime**:
- **No Node.js / Python dependencies required**: No `package.json`, `pnpm`, or external scripts.
- **Cross-Agent Execution**: All 17 skills are declarative `SKILL.md` runbooks executed directly by the agent using its built-in file reading, editing, shell (`git`, `grep`), and analysis tools.
- **Portability**: Drop `all-in-one-agent` into any directory, and Claude Code, OpenAI Codex, or Gemini CLI will immediately discover and follow the protocol.

---

## 🚀 Initializing in a Parent Workspace (`/init-aio-agent`)

When you clone `all-in-one-agent` into a parent directory alongside project repositories:

1. Open the workspace in any agent (Claude Code, Codex, or Gemini CLI).
2. Invoke the skill:
   ```text
   /init-aio-agent
   ```
3. The agent will:
   - Create or update `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, and `README.md` in the parent directory.
   - Auto-detect sibling repositories (e.g., `metronome/`, `anhoc/`, `anchi/`).
   - Scaffold `insight/registry.json` and project knowledge trees in `insight/` in the parent root.

## 🛡️ The Shared Protocol: 7 Steps

Every skill adheres strictly to [`shared/insight-protocol.md`](./shared/insight-protocol.md):
1. **Resolve Repository**: Look up target repository in `../insight/registry.json`.
2. **Read Insight First**: Consult `../insight/<repo>/INDEX.md` and relevant architecture docs.
3. **Check Freshness**: Check `manifest.json` against current source commits and file hashes using native tools.
4. **Targeted Exploration**: Inspect source code *only* when insight is missing or stale.
5. **Execute Skill**: Carry out procedure adhering to documented conventions.
6. **Synchronize Insight**: Update changed contracts, diagrams, and `manifest.json` directly.
7. **Report**: Summarize completed work, modified files, and refreshed knowledge.
